# gestalt-drches
Лендинг гештальт-терапевта (@Drches, vk.ru/sches). ref 6YBRPGS8NY. Идея: «фигура и фон». Hero-поле кругов, sticky-сцена 7x7 по форматам, пикер формата, калькулятор аренды кабинетов (350/400 ₽/час).
Ждём: имя специалиста, фото, адрес кабинетов, формат онлайн/офлайн, реквизиты для privacy.
